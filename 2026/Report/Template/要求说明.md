# 电赛 LaTeX 报告模板 —— 格式要求说明

> 本模板位于 `Template/Latex/`，XeLaTeX 编译。使用前请确保系统安装了 SimSun（宋体）、SimHei（黑体）、KaiTi（楷体）、Times New Roman 字体。

---

## 一、整体规格

| 项目 | 要求 |
|------|------|
| 纸张 | A4，纵向打印 |
| 页边距 | 左 2.5cm，右 2.5cm，上 **≥3cm**（空白区内不得有任何文字），下 2.5cm |
| 正文行距 | **固定值 22 磅** |
| 正文字体 | 中文**宋体**（SimSun），英文/数字 **Times New Roman** |
| 正文字号 | **小四**（12pt） |
| 正文页数 | **≤ 8 页**（从正文第 1 页起算，封面、摘要、目录不计入） |
| 页码 | **右下角**，从正文第 1 页开始标注 |

---

## 二、封面（扉页）

- **标题**：黑体三号（16pt），居中
- **logo**：`pic/电赛logo.png`，宽度 55% 页宽，居中
- **日期**：宋体四号（14pt），居中
- **不标注**作者姓名（竞赛要求匿名评审）
- 封面页**不标页码**

---

## 三、摘要

- **格式**：中文宋体 / 英文 Times New Roman，小四（12pt），**顶格**（不缩进），行距 22 磅
- **字数**：**≤ 300 汉字**
- **"摘要："**：加粗（宋体加粗 → 映射黑体）
- **"关键词："**：同上格式，关键词之间用**空格**分隔
- 摘要页**不标页码**

---

## 四、目录

- 自动生成（`\tableofcontents`）
- 目录页**不标页码**

---

## 五、标题层级

| 级别 | 编号示例 | 字体 | 字号 | 段前 | 段后 |
|------|---------|------|------|------|------|
| 一级标题 | `1.` | 黑体（SimHei） | 四号（14pt） | 14pt | 8pt |
| 二级标题 | `1.1` | 黑体（SimHei） | 小四（12pt） | 10pt | 5pt |
| 三级标题 | `1.1.1` | 黑体（SimHei） | 小四（12pt） | 6pt | 2pt |

- 各级标题字号可自定，本模板采用上述规格
- 三个级别的间距逐级递减，形成清晰的层次感

---

## 六、图表

### 图片
- 使用 `\begin{figure}[H]` 强制置于当前位置
- 图片放入 `pic/` 文件夹，引用路径 `../pic/xxx.png`
- **标题在图片正下方**

### 表格
- 使用 **三线表**（`\toprule` / `\midrule` / `\bottomrule`）
- 使用 `tabularx` + `\textwidth` 占满页宽，列宽均匀分布
- 列类型使用居中 `C` 列（已定义：`>{\centering\arraybackslash}X`）
- **标题在表格正下方**
- 使用 `[H]` 确保表格不跨页

### 图表标题格式
- 黑体 / Times New Roman **五号**（10.5pt）**加粗**

---

## 七、代码块

- 使用 `listings` 宏包，等宽字体
- 行号左侧显示，可自动换行
- 背景色浅灰（`backcolour`）

---

## 八、编译方式

```bash
cd Template/Latex/src
xelatex -interaction=nonstopmode Template.tex   # 编译两次以解析交叉引用
xelatex -interaction=nonstopmode Template.tex
```

输出 PDF：`Template/Latex/src/Template.pdf`

## 九、章节结构模板

```
1. 系统方案设计
  1.1 方案论证与选择
    1.1.1 [关键模块一]的论证
    1.1.2 [关键模块二]的论证
  1.2 总体方案描述

2. 理论分析与计算
  2.1 核心理论/模型分析
  2.2 关键算法分析
  2.3 相关参数计算

3. 电路与程序设计
  3.1 电路设计分析
  3.2 控制程序设计
  3.3 视觉程序设计（按需改名）

4. 设计报告测试方案与测试结果
  4.1 测试环境
  4.2 测试方案
  4.3 测试结果与数据
  4.4 测试结果分析
```

## 十、快速上手检查清单

- [ ] 封面：替换 `[题号]` `[题目]` `[日期]`
- [ ] 摘要：≤300 汉字，关键词空格分隔
- [ ] 图片：放入 `pic/`，取消注释 `\includegraphics`
- [ ] 表格：使用 `tabularx}{...}{C...C}` 格式，标题在表格下方
- [ ] 正文：严格 ≤8 页
- [ ] 页眉：3cm 空白区域内无任何文字
- [ ] 编译：XeLaTeX × 2 遍
