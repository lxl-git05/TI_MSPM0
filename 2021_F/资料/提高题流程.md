# 提高题流程

## 1. 提高1

* 小车1识别数字，上药，出发
* 小车1到达目的地（3 or 4），**新增：发送3和4的相对位置给小车2**
* 小车2识别数字，上药，出发（小车2和小车1的数字相同）
* 小车2到达丁字路口（4个数字的丁字路口）
* 小车1卸载药品，回程
* 小车1到达十字路口并转向**完成后**发送`@Car2_Enable_Back$#`
* 小车2收到命令之后掉头前往目的地（和小车1相同）
* 小车1，2都到达终点



## 2. 提高2

+ 小车1识别数字，上药，出发
+ 小车1到达目的地（5,6,7,8）
+ 小车2识别自己的数字，获取小车1的数字之后出发（**不需要上药**）
+ 小车2去到停止点
  + 分两种情况：
    + 小车1和2在同侧
    + 小车1和2在不同侧
+ 小车1卸载药品，回程
+ 小车1在丁字路口（4数字丁字路口）转向完成后发送：`@Car2_Enable_Back$#`
+ 小车1回程，同时小车2到达药物点，完成任务



## 蓝牙收发

+ Car1:发送

```c
// 1. 小车1的目标数字
Serial_Printf_Normal(&Serial3, "@Car1_Target=%d$#" , Target_Num) ;
// 2. 允许小车2出发
Serial_Printf_Normal(&Serial3, "@Car2_Enable_Back$#") ;
// 3. 数模信息
Serial_Printf_Normal(&Serial3, "@rd_two_1=%d$#",Road2[0]) ; // 发送中端数模给小车2
Serial_Printf_Normal(&Serial3, "@rd_two_2=%d$#",Road2[1]) ; // 发送中端数模给小车2

Serial_Printf_Normal(&Serial3, "@rd_three_1=%d$#",Road3[0]) ; // 发送远端数模给小车2
Serial_Printf_Normal(&Serial3, "@rd_three_2=%d$#",Road3[1]) ; // 发送远端数模给小车2
Serial_Printf_Normal(&Serial3, "@rd_three_3=%d$#",Road3[2]) ; // 发送远端数模给小车2
Serial_Printf_Normal(&Serial3, "@rd_three_4=%d$#",Road3[3]) ; // 发送远端数模给小车2

Serial_Printf_Normal(&Serial3, "@rd_four_L_1=%d$#",Road4_L[0]) ; // 发送终点段数模给小车2
Serial_Printf_Normal(&Serial3, "@rd_four_L_2=%d$#",Road4_L[1]) ; // 发送终点段数模给小车2

Serial_Printf_Normal(&Serial3, "@rd_four_R_1=%d$#",Road4_R[0]) ; // 发送终点段数模给小车2
Serial_Printf_Normal(&Serial3, "@rd_four_R_2=%d$#",Road4_R[1]) ; // 发送终点段数模给小车2
```



+ 数据帧格式

1. **帧头**
2. **数据长度**
3. Car1_TargetNum
4. Is_Car2_Enable_Back: **100 -> true 0->false**
5. road_2_L * 10 + road2_R
6. road_3_1 * 1000 + road_3_2 * 100 + road_3_3 * 10 + road_3_4 * 1
7. road_4_L_1 * 10 + road_4_L_2 * 1
8. road_4_R_1 * 10 + road_4_R_2 * 1
9.  **帧尾**
