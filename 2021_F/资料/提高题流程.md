# 提高题流程

## 1. 提高1

* 小车1识别数字，上药，出发
* 小车1到达目的地（3 or 4）
* 小车2识别数字，上药，出发（小车2和小车1的数字相同）
* 小车2到达丁字路口（4个数字的丁字路口）
* 小车1卸载药品，回程
* 小车1到达十字路口并转向**完成后**发送`@Car2_Enable_Back$#`
* 小车2收到命令之后掉头前往目的地（和小车1相同）
* 小车1，2都到达终点



## 2. 提高2

+ 小车1识别数字，上药，出发
+ 小车1到达目的地（5,6,7,8），**之后**发送信息给小车2：`@Car1_Target=%d$#`
+ 小车2识别自己的数字，获取小车1的数字之后出发（**不需要上药**）
+ 小车2去到停止点
  + 分两种情况：
    + 小车1和2在同侧
    + 小车1和2在不同侧
+ 小车1卸载药品，回程
+ 小车1在丁字路口（4数字丁字路口）转向完成后发送：`@Car2_Enable_Back$#`
+ 小车1回程，同时小车2到达药物点，完成任务
