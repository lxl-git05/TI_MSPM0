

# 基础题流程

## 1. 基础1

+ 小车识别数字
+ 小车上药
+ 小车启动去往1 / 2
+ 小车到达药房
+ 取出小车的药
+ 小车回程到达终点

## 2. 基础2

+ 和基础1差不多

## 3. 基础3

+ 和基础1差不多

# 提高题流程

## 1. 提高1

* 小车1识别数字，上药，出发
* 小车1到达目的地（3 or 4），**新增：发送3和4的相对位置给小车2**
* 小车2识别数字，上药，出发（小车2和小车1的数字相同）
* 小车2到达丁字路口（4个数字的丁字路口）
* 小车1卸载药品，回程
* 小车1到达十字路口并转向**完成后**发送`@Car2_Enable_Back$#`
* 小车2收到命令之后掉头前往目的地（和小车1相同）
* 小车1，2都到达终点

## 2. 提高2

+ 小车1识别数字并且上药，出发
+ 小车1到达目的地（5,6,7,8），发送允许信息，允许小车2识别自己数字之后出发
+ 小车2识别自己的数字，获取小车1的允许之后出发（**不需要上药**）
+ 小车2去到目标终点，到达终点之后发送命令允许小车1回程，小车2任务完成
+ 小车1卸载药品，等待回程指令，回程，完成任务

1. **帧头**
2. **数据长度**

8. road_4_R_1 * 10 + road_4_R_2 * 1
